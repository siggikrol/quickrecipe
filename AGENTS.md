# Recipe content conventions

Use recipe and category names for filenames, recipe IDs, variables, and comments. Never reference recipe publishers, websites, or source authors in code, filenames, identifiers, recipe text, or metadata. Do not add attribution links, provenance fields, or source URLs.

Preserve cooking quantities and methods unless the user requests changes. Keep English, Icelandic, and Polish recipe text aligned. Preserve saved favorites and selection when renaming recipe IDs. Keep app, service worker, and HTML asset versions aligned, and run the existing checks after changes.
